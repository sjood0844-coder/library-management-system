Library Management System Database

Project Overview

This project focuses on designing and implementing a relational database for a Public Library Management System using MySQL and SQL.

The system is designed to organize and manage library operations, including books, categories, members, borrowing transactions, and study room reservations.

Project Objectives

* Organize library information efficiently.
* Manage books and their categories.
* Store and manage library member information.
* Track book borrowing and return transactions.
* Manage study hall reservations.

Database Design

The database includes the following entities:

* Category: Stores book categories.
* Books: Stores book information and details.
* Members: Stores library member information.
* Member_Phones: Stores members’ phone numbers.
* Borrowings: Tracks borrowing and returning transactions.
* Halls: Stores library hall information.
* Reservations: Manages hall reservations.

Tools & Technologies

* MySQL
* SQL
* Entity Relationship Diagram (ERD)
* Relational Database Design

SQL Concepts Applied

* CREATE TABLE and INSERT
* Primary Keys and Foreign Keys
* Database Constraints
* SELECT Queries
* JOIN Operations
* GROUP BY and Aggregate Functions
* Subqueries
* SQL Views

Project Outcomes

A structured relational database was designed and implemented to support library operations, maintain data relationships and integrity, and generate useful reports through SQL queries and views.
